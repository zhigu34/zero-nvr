# Archived documents

## zero_nvr_prototype.html

`zero_nvr_prototype.html` is a 4,157-line / 256 KB static HTML mockup of the whole zero-nvr UI.
It is a **frozen historical design reference**: it is no longer maintained, not served by the
product, and has been superseded by the real Vue frontend under `frontend/src/views/` (and
`frontend/src/layouts/`).

It is kept only because two production source files still cite it by name or by its internal line
numbers: `frontend/src/layouts/AppShell.vue` and `frontend/src/views/CamerasView.vue`. Until those
comments are repointed, treat this archive as the target of those citations. Do not edit the file.
